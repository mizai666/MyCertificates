## 文件说明

**命名规则**：`YYYY-MM-DD-英文简称.扩展名`，日期取证书落款日期，便于按时间排序。

**目录结构**

```
MyCertificates/
├── certificates/      # 23 张证书图片
├── notices/           # 3 份官方公示 / 名单文件
└── awards-registry.xlsx  # 获奖登记表（31 条，含未配图的记录）
```

- `awards-registry.xlsx` 为本人按学期整理的获奖台账，字段包含奖励名称、等级、日期、级别、类别与颁奖单位，可作为完整清单核对。
- 部分证书为团队获奖（省级创意赛、迪文杯、挑战杯、物联网技能赛、天梯赛），证书上的姓名可能为多位队员。
- 三张原图为竖拍横排（迪文杯、挑战杯、物联网技能赛），已旋转为正向。
